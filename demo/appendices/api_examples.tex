\section{Command Reference Examples}
\label{app:api-examples}

This appendix provides practical examples of the Lane LaTeX Template API commands and environments.

\subsection{Title Page Commands}

\subsubsection{Article Title Variants}

The template provides several title commands for different contexts:

\begin{verbatim}
% Standard title (auto-adjusts size based on length)
\articletitle{The Impact of Typography on Academic Writing}

% Title with acknowledgment footnote
\articletitlefootnote{Typography in Academic Papers}
  {We thank the LaTeX community for helpful comments.}

% Compact title for papers with many authors
\articletitlecompact{A Concise Title}
\end{verbatim}

\subsubsection{Complete Title Page Example}

\begin{verbatim}
\thispagestyle{empty}
\titlefootnotesetup
\begin{center}
  \vspace*{\titlespaceminor}
  \articletitle{Demonstrating Professional Typography}
  \articleauthors{Jane Smith\footnote{University, jane@example.edu}
    \authorspace John Doe\footnote{Institute, john@example.edu}}
  \articledate{\today}
  \begin{articleabstract}
    This paper demonstrates the comprehensive typography 
    system provided by the Lane LaTeX Template...
  \end{articleabstract}
  \articlekeywords{typography, LaTeX, academic writing}
  \articlejel{A10, B20, C30}
\end{center}
\clearpage
\titlefootnotereset
\end{verbatim}

\subsection{Typography Commands}

\subsubsection{Emphasis Hierarchy}

Use the standard LaTeX emphasis commands for different content types:

\begin{itemize}
\item \emph{Basic emphasis:} Use \verb|\emph{text}| for \emph{standard emphasis}
\item \textbf{Strong emphasis:} Use \verb|\textbf{text}| for \textbf{critical terms}
\item \emph{Technical terms:} Use \verb|\emph{baseline grid}| for the \emph{baseline grid}
\item \textsc{Person names:} Use \verb|\textsc{Robert Bringhurst}| for \textsc{Robert Bringhurst}
\item \textsc{Acronyms:} Use \verb|\textsc{PDF}| for \textsc{PDF} format
\item \emph{Published works:} Use \verb|\emph{The Elements of Typographic Style}| for \emph{The Elements of Typographic Style}
\item \textsc{Metadata:} Use \verb|\textsc{Version 1.0}| for \textsc{Version 1.0}
\item \textbf{\textsc{Critical notices:}} Use \verb|\textbf{\textsc{WARNING}}| for \textbf{\textsc{WARNING}} messages
\end{itemize}

\subsubsection{Section Opening Styles}

For professional section openings:

\begin{verbatim}
% First line in small caps
\sectionopening{This opening line appears in elegant small caps,}
continuing with normal text for the rest of the paragraph.
\end{verbatim}

\subsection{Special Characters and Symbols}

\subsubsection{Dash Usage}

Use standard LaTeX dashes:

\begin{itemize}
\item Em dash: Typography---the art of arranging type---is essential
\item Classic em dash: Typography---without spaces---for traditional style
\item En dash for ranges: Pages 10--20
\item Years: 2020--2025
\end{itemize}

\subsubsection{Currency and Technical Symbols}

Professional spacing for all symbols:

\begin{itemize}
\item Currency: \texteuro 100, \textsterling 50, \textyen 1000, 50\textcent
\item Technical: 25\textdegree C, Area = 100m\textsuperscript{2}
\item Legal: Product\texttrademark, Company\textregistered, \copyright 2025
\item Mathematical in text: 5\textpm 2, 3\texttimes 4, 12\textdiv 3, $\pi \approx 3.14$
\end{itemize}

\subsection{Table Environments}

\subsubsection{Tables with Standard Row Heights}

\begin{table}[h]

\subsubsection{Table Notes}

Load \texttt{threeparttable} in the document when a table needs notes:

\begin{verbatim}
\begin{threeparttable}
  \begin{tabular}{@{}lr@{}}
    \toprule
    Item & Value \\
    \bottomrule
  \end{tabular}
  \begin{tablenotes}
    \item \emph{Notes:} All values in constant 2020 dollars.
  \end{tablenotes}
\end{threeparttable}
\end{verbatim}

\subsection{Cross-Reference Commands}

The document loads and configures cleveref for intelligent cross-referencing:

\begin{itemize}

\subsection{Spacing Commands}

\subsubsection{Vertical Space}

The 13.2pt spacing quantum is internal to the package (ADR-0006), so a
document states the space it wants directly:

\begin{verbatim}
\vspace{13.2pt}   % One quantum
\vspace{26.4pt}   % Two quanta
\vspace{6.6pt}    % Half a quantum
\end{verbatim}

\subsection{Complete Example Document}

Here's a minimal complete document using the template:

\begin{verbatim}
\documentclass[11pt]{article}
\usepackage[backend=biber,style=authoryear]{biblatex}
\usepackage{lanepaper}
\addbibresource{references.bib}

\begin{document}

% Title page
\thispagestyle{empty}
\titlefootnotesetup
\begin{center}
  \vspace*{\titlespaceminor}
  \articletitle{Your Paper Title}
  \articleauthors{Your Name\footnote{Your Institution}}
  \articledate{\today}
  \begin{articleabstract}
    Your abstract here...
  \end{articleabstract}
  \articlekeywords{keyword1, keyword2}
\end{center}
\clearpage
\titlefootnotereset

% Main content
\section{Introduction}

\sectionopening{This paper examines} the role of typography
in academic communication...

% Bibliography
\printbibliography

\end{document}
\end{verbatim}
